# Tile images

The 39 SVG files in this directory (Man1..Man9, Man5-Dora, Pin1..Pin9, Pin5-Dora, Sou1..Sou9, Sou5-Dora, Ton, Nan,
Shaa, Pei, Haku, Hatsu, Chun, Back, Front) are the "Regular" set of **riichi-mahjong-tiles** by FluffyStuff:

- source: https://github.com/FluffyStuff/riichi-mahjong-tiles (files fetched from
  `https://raw.githubusercontent.com/FluffyStuff/riichi-mahjong-tiles/master/Regular/<Name>.svg`)
- license: CC0 1.0 Universal (public domain dedication), https://creativecommons.org/publicdomain/zero/1.0/

They are vendored unchanged. `Front.svg` is the blank tile body the face files are drawn over; `Back.svg` is a face-down
tile.
